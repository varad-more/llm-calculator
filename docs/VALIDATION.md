# Validation

Signed relative error of our prediction against the engine's own startup log
(`predicted - measured) / measured`; negative means we under-predict.

CI tolerances: weights ±1%, KV ±5%, overhead ±15%.

_No validation cases yet._ Every number this tool prints is **predicted**, not measured.

If you have a GPU, the fastest way to help is to paste a real engine startup log into an issue:
https://github.com/varad-more/llmsize/issues/new?template=validation-log.yml

Generated by `pnpm validate` from `validation/cases/`. Do not edit by hand.
