# Rentable machines

What a sizing costs when you do not own the GPU. Every row resolves to an entry in
[HARDWARE.md](./HARDWARE.md), so the allocator that says whether a model fits is the same one
either way.

**Prices are a dated snapshot.** on-demand, Linux, no pre-installed software, `us-east-1`, read on
**2026-09-02** from [the AWS price list](https://b0.p.awsstatic.com/pricing/2.0/meteredUnitMaps/ec2/USD/current/ec2-ondemand-without-sec-sel/US%20East%20(N.%20Virginia)/Linux/index.json). They move, and
nothing re-fetches them; the UI lets you substitute your own spot or savings-plan rate.

Host figures come from the [AWS accelerated computing tables](https://docs.aws.amazon.com/ec2/latest/instancetypes/ac.html). Network is
the **sustained** rate, not the burst ceiling a small instance holds for a few minutes.

AWS EC2 GPU instances, us-east-1, Linux, on-demand. Prices move: every row carries the date it was read, and the UI lets you replace the rate with your own (spot, savings plan, negotiated). Only the cheapest size at each (family, GPU count) is listed — a g5.16xlarge has the same single A10G as a g5.xlarge and costs four times as much, so it can never win on cost per token; pick a larger size when you need the vCPUs or the host RAM. Families whose GPU is not yet in data/gpus.json are omitted rather than guessed: g4dn (T4), p3 (V100), g7/g7e (RTX PRO 6000 Blackwell), p6-b300 (B300).
